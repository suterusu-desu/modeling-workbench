# Integration scope

The shipped workbench uses direct owner-controlled service calls and sessions.
The reusable queue, preservation, guide fitting, numerical preparation, evidence,
review, learning, native jobs, retention and recovery remain part of that system.
There is no required inference transport, credential, provider ledger or external
skill dependency for modeling.

Source implementation, clean installation, private adapter qualification, operator
adoption and actual native use are separate verification stages. Do not treat
this document as a character modeling queue; current private workspace authority
selects the next correction.

Outstanding general capabilities require actual need and evidence: new rig/scene
adapter implementations, additional qualified worker platforms and cross-character
quality studies. Do not turn these limits into open-ended prerequisites for using
verified tools. Preserve earlier experiments privately and promote only supported
general methods with explicit applicability and limits.
