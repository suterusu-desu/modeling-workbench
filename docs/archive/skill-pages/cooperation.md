# Cooperative execution and review

Compose independent useful catalogs with `compose_catalogs`. The same owner queue
keeps exact prerequisites, immutable results and native serialization. Explicit
owner priorities select eligible work. A blocked review dependency need not stop
independent diagnosis, preparation or recovery that is already authorized.

`session.run(max_steps=..., feedback_timeout=..., on_handoff=...)` runs a finite
supervised interval. It writes an exact `handoff.json` containing the candidate,
review basis, actual evidence and waiting tasks. Review submission is an immutable
episode fact and separate index, so it cannot overwrite the execution queue.
The default feedback timeout is zero; a positive timeout watches only the review
mailbox, not Blender or a provider. Cancellation remains available.

Return actual image interpretation through `record_review` and preserve supported
techniques with the experience API. Dependent native work uses that exact review
and fresh inputs. Unrelated qualified work may continue; there is no second native
writer, automatic scope expansion or unattended authorization.

Known computations, saves and recovery steps belong inside qualified operations.
Offer work only when it resolves a named uncertainty or improves the model.
No inference provider is needed to schedule or continue these operations.
