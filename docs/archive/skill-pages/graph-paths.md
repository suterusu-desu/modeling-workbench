# Bounded paths in a declared graph

Use `inspect_graph_path(case_path, expected_state, max_nodes=100000, max_edges=500000)` for a finite connectivity question over a pinned graph. It is an offline service/recipe diagnostic, not a geometric target generator. This complements ordered surface correspondence: disconnected planar cuts do not rule out a path in a separately established full3D graph, and a graph route does not establish anatomical correspondence.

A version-1 case has `question`, matching historical `state` (`source_state_id`, `pose`, `frame`, `units`, `dependency_fingerprint`), `graph` and `selection` with their own `meaning`/`evidence`, `start`/`goal` string node identities and `arrays: {path, sha256}`. `graph.coverage` is `{status, missing}`; status is `unknown`, `declared_subset` or `complete_for_declared_graph`, with no missing items for the last. Declare actual edge semantics: a native vertex-edge path, a triangle dual graph joined by shared edges, and a spatial section graph mean different things. State all domain exclusions and unseen geometry.

The NPZ has distinct ordered integer/string `node_ids`, unique undirected integer `edges` indexing those nodes, and independent boolean vectors `allowed_nodes` and `allowed_edges`. Both selections are enforced. A whole-object path cannot stand in for the selected-edge query. Coincident coordinates do not create adjacency. Input limits are 250,000 nodes and 1,500,000 edges; malformed or larger graphs are refused rather than truncated.

The breadth-first search returns `path_found`, `no_path_in_declared_selection`, `endpoint_outside_selection` or `incomplete_budget`. Budgets limit discovered nodes and examined directed adjacency entries. Exhaustion stays incomplete even if a candidate path was already found. This budget applies to graph traversal, not file ingestion or adjacency construction. The `summary` reports actual work, budgets, selection counts and coverage.

A completed search distinguishes `unique_shortest_path` from `ambiguous_shortest_paths`. Exact equal-length alternatives are retained in the predecessor graph with one deterministic candidate path. Uniqueness is only among shortest paths; longer alternatives are not enumerated. Bounded `reads` expose the path, predecessor evidence, pinned case and limits. No path in a supplied subset establishes global unreachability, hidden-surface absence or missing anatomy. `native_ready` and `target_admission` remain false.
