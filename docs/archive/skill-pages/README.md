# Archived skill pages

These pages left the operator skill when it became a short router around the construction-first verbs. Their modules
were never or rarely used in real modeling, belonged to an orchestration layer built for an inference service that has
since been removed, or recorded development history rather than operation. The pages are kept here, unchanged, for
anyone who still uses the modules; the modules themselves remain in the package until they are archived on a tagged
commit.

| Page | Why it left the skill |
|---|---|
| controller, work-queue, cooperation, method-control, typed-control, candidate-pipeline | orchestration for menu-driven choices by an inference service; direct operation runs three fixed steps |
| component-catalog, graph-paths, topology-lineage, surface-correspondence, target-domain, recipes, responses-and-transfer | offline diagnostics with no recorded use in modeling |
| provider-workflows, native-transactions, execution-contracts | composition layers with no recorded use; the generation ledger, isolated runner and receipts cover the used routes |
| design-evolution | development history; the README and the skill describe shipped behaviour |
